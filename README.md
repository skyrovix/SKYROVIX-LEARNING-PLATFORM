# 🚀 Skyrovix — Next-Generation Developer Learning Platform

Skyrovix is a production-grade, state-of-the-art developer education platform featuring interactive video masterclasses, 435+ deep documentation text tracks, a learner dashboard, an admin console, and an in-browser code execution sandbox.

---

## 🌟 Key Features

### 🎬 10 Masterclass Video Courses
1. **Full Stack Web Development Masterclass** (Architecture, React, Node.js, PostgreSQL, Docker)
2. **HTML5 Modern Semantic & Accessible Web** (DOM, WCAG 2.1, ARIA, SEO)
3. **CSS3 & Modern Responsive Design Systems** (CSS Grid, Flexbox, Animations, Container Queries)
4. **JavaScript: The Hard Parts & Modern ES2024** (Event Loop, Closures, Microtasks, Async/Await)
5. **Frontend with React 19** (Server Actions, `useActionState`, `useOptimistic`, TanStack Query)
6. **Backend with Node.js** (Streams, Libuv, WebSockets, JWT/OAuth2, Microservices)
7. **Database Engineering** (PostgreSQL, MongoDB, Redis, B-Tree Indexes, EXPLAIN ANALYZE)
8. **Next.js 15 Full-Stack App Router** (RSC, Streaming Suspense, Partial Prerendering)
9. **Frontend Development: Architecture & Core** (Core Web Vitals, INP, Feature-Sliced Design)
10. **Backend Development: Distributed Systems** (Event-Driven, Kafka, gRPC, Idempotency)

*Each video course includes interactive timestamp chapters, live lecture notes with timestamp anchors, full transcripts, downloadable architecture resources, and knowledge-check quizzes.*

---

### 📖 12 Text-Based Interactive Documentation Tracks (435 Lessons)
Built directly from the curriculum in `course-content`:
- **HTML5** (60 Chapters)
- **CSS3** (90 Chapters)
- **Modern JavaScript** (30 Chapters)
- **Python Core to Advanced** (60 Chapters)
- **MySQL & Relational Databases** (15 Chapters)
- **Java Enterprise & OOP** (60 Chapters)
- **PHP 8 Web Development** (55 Chapters)
- **Django Framework** (15 Chapters)
- **NumPy Numerical Computing** (12 Chapters)
- **Pandas Data Analysis** (15 Chapters)

*Features reading time estimates, font scaling, reading contrast themes (Midnight/Slate), code syntax highlighting, copy-to-clipboard, and one-click **"Run in Sandbox"**.*

---

### 👤 User (Learner) Dashboard
- **Streak & Knowledge Points**: 7-day study streak, XP level tracker.
- **Continue Learning**: Quick-resume hero banner of the active course.
- **My Enrolled Courses**: Filterable by Video, Text, or Completed tracks with live progress bars.
- **Interactive Code Sandbox**: Live HTML/CSS/JS preview iframe and Python algorithm simulator.
- **Notes & Bookmarks Library**: Search and jump back to exact video timestamps and text chapters.
- **Certificates of Achievement**: Verifiable official certificates with credential IDs, printable or downloadable.
- **Weekly Learning Analytics**: Visual study velocity chart (hours studied Mon–Sun) and milestone goals.

---

### 🛡️ Admin Dashboard & Control Center
- **Executive KPIs**: Real-time student count, published courses, completion rates, and satisfaction metrics.
- **Course Catalog Manager**: Search, filter, edit, delete, and publish new Video or Text courses.
- **Curriculum & Lesson Studio**: Add modules, video stream URLs, and author text lessons using a split-pane live Markdown editor.
- **Student Roster**: Inspect individual learner progress, enrolled courses, and manage roles.
- **One-Click Role Switcher**: Switch between **Learner Mode** and **Admin Mode** directly from the top navigation bar.

---

## 🛠️ Quick Start

```bash
# 1. Start the development server
npm run dev

# 2. Build for production
npm run build

# 3. Preview production build
npm run preview
```

Open [http://localhost:3000](http://localhost:3000) in your browser to experience Skyrovix.
