# Responsive UI Audit
1. Inspect the app structure and identify key pages, shared components, and breakpoints.
2. Review layouts at narrow mobile, large mobile, tablet, laptop, and wide desktop widths.
3. Check horizontal overflow, clipped content, awkward wrapping, image crops, spacing, and grid collapse.
4. Check navigation, menus, dialogs, forms, buttons, and touch targets.
5. Verify semantic structure, labels, keyboard navigation, visible focus, and color contrast.
6. Respect prefers-reduced-motion and ensure content is usable without animation.
7. Check loading states, empty states, error states, and long-content behavior.
8. Optimize images and avoid unnecessary scripts, dependencies, and continuous animation loops.
9. Use the project's available test, lint, type-check, and build commands.
10. Fix issues in the existing architecture; do not rewrite unrelated functionality.
11. Report findings by severity, changes made, checks run, and any remaining issues.
