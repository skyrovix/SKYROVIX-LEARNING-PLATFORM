# Cinematic Web Motion
1. Inspect installed animation libraries and use the existing stack where possible.
2. Use Motion/Framer Motion for component transitions; use GSAP only for timelines or complex scroll sequences that justify it; use CSS for simple transitions.
3. Create a motion language with consistent easing, duration, stagger, and distance.
4. Use restrained entrance reveals, text reveals, staggered groups, and section transitions.
5. Use scroll-triggered motion selectively; never animate every paragraph or block.
6. Use parallax only for suitable visual layers and keep it subtle.
7. Add polished button, link, navigation, card, and icon micro-interactions.
8. Avoid scroll hijacking, forced horizontal scrolling, flashing, excessive zoom, and long blocking intro animations.
9. Prefer transform and opacity; avoid animating layout-heavy properties.
10. Respect prefers-reduced-motion and provide touch-friendly behavior.
11. Test performance and verify content remains visible if animation fails.
Target smooth motion and 60 FPS where practical, without promising performance on every device.
