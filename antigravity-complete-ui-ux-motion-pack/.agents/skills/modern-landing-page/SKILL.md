# Modern Landing Page
1. Inspect the product, audience, brand assets, existing routes, and content before designing.
2. Keep the value proposition specific, honest, and visible in the first viewport.
3. Design a purposeful hero: headline, supporting copy, primary CTA, optional secondary CTA, and a relevant visual.
4. Build a clear narrative: problem or context, benefits, proof supplied by the user, workflow or features, FAQ, and final CTA as appropriate.
5. Use consistent section widths, spacing, typography, buttons, and image treatments.
6. Use real supplied screenshots, logos, and assets; never fabricate testimonials, customer logos, statistics, or endorsements.
7. Keep navigation understandable and implement a usable mobile menu.
8. Make CTA destinations and form behavior functional; do not create inert controls.
9. Add subtle motion that supports the narrative, not distracts from it.
10. Check accessibility, responsive behavior, SEO basics, loading performance, and existing functionality.
Avoid generic filler sections and repetitive card layouts. Adapt section order and content to the actual product.
