# Premium UI & Motion
1. Inspect the project, framework, routes, components, assets, and existing design system before editing.
2. Preserve existing functionality, content, routes, integrations, and framework conventions.
3. Establish a visual direction suited to the brand: editorial, premium SaaS, creative studio, minimal luxury, or another intentional style.
4. Define reusable design tokens for colors, typography, spacing, radii, shadows, and motion.
5. Create strong hierarchy with deliberate composition, whitespace, alignment, and readable contrast.
6. Build a clear hero with concise value proposition and meaningful primary action.
7. Use cards only when they improve grouping; avoid generic card grids everywhere.
8. Make mobile, tablet, and desktop layouts intentional, not merely scaled versions.
9. Add purposeful hover, focus, active, and pressed states.
10. Run available lint, type-check, and build checks; fix regressions and report what was tested.
Quality rules: no random gradients/glows, no excessive animation, no fabricated claims, no inaccessible low-contrast text, and no breaking existing features.
