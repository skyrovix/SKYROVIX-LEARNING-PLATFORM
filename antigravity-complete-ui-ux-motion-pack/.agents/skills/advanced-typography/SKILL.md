# Advanced Typography
1. Inspect existing fonts, brand identity, loading strategy, and CSS conventions.
2. Choose a purposeful font system; consider Space Grotesk, Manrope, Sora, Plus Jakarta Sans, DM Sans, and Inter where appropriate.
3. Use at most two primary font families unless the design clearly requires more.
4. Establish a responsive type scale using CSS clamp() for display headings and section titles.
5. Tune font weight, line-height, letter spacing, line length, and paragraph measure for readability.
6. Use strong hierarchy rather than making all text oversized or bold.
7. Apply gradient, outlined, animated, or masked text sparingly and maintain accessible contrast.
8. Ensure headings wrap cleanly at narrow widths and do not overflow.
9. Load fonts efficiently; prefer existing local assets or a reliable font provider already used by the project.
10. Verify typography on mobile, tablet, and desktop.
Avoid excessive all-caps, arbitrary font mixing, tiny low-contrast labels, and decorative effects that reduce legibility.
